# Brand assets — BCL Fantasy logo

**The mark:** a red ball striking three gold stumps while a bail flies off, over a teal crease line, on a deep-navy
tile. Palette = the app's own navy / gold / teal plus cricket-ball red. One definition generates every file, so
they cannot drift apart: `tools/gen_brand.js` (run from the repo root: `node tools/gen_brand.js`).

| File (`Static/brand/`) | Use |
|---|---|
| `icon.svg` | rounded tile — app bar, loading + login screens, browser-tab favicon, web-app icon ("any") |
| `icon-square.svg` | full-bleed square — Apple touch icon + Android maskable icon source |
| `mark.svg` | the mark alone on a transparent background — empty-state illustrations, dark surfaces |
| `logo-lockup.svg` | tile + geometric "BCL" + "FANTASY" — documents, sharing, README |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `favicon-32.png` | rasterised by `tools/make_brand_pngs.ps1` (headless Chrome/Edge) |

Wired in: `templates/index.html` (favicon + apple-touch-icon links, loading screen, app bar, login hero),
`routes.py` (`/manifest.json` icons incl. maskable, `/offline` page), `Static/ui.js` (empty-state illustration).

**Wordmark in the app** is live text, not an image: `BCL` (900 weight, white) + `FANTASY` (700, gold, tracked caps) —
classes `.bn-bcl` / `.bn-fan` in `Static/screens.css`. The monoline "BCL" in `logo-lockup.svg` is drawn as paths so the
file does not depend on installed fonts (only the small "FANTASY" line uses a system font stack).

**Regenerating:** edit the colours/geometry in `tools/gen_brand.js`, run it, then run the PNG script, then commit.
To update the Android app icon: copy `Static/brand/android/*.xml` over the two drawables of the same name and rebuild the APK.

## Android launcher icon (WebView app in `C:UsersSahilDownloadsipl_fantasy_app`)
Generated by `node tools/gen_android_icon.js` into `Static/brand/android/`; preview the real files under phone masks with
`node tools/preview_android_icon.js`. An adaptive icon is cropped by the launcher, so it has its own composition: the artwork is scaled
until its farthest corner is inside the 66dp safe circle (the script refuses to write otherwise), and the crease line lives in the
BACKGROUND layer where cropping is harmless. Layers: `ic_launcher_foreground` (gold stumps, bails, red ball), `ic_launcher_background`
(navy gradient + teal glow + crease), `ic_launcher_monochrome` (Android 13 themed icon), `ic_splash_logo` (full tile for the native
splash/error screens). Copy them into `app/src/main/res/drawable/`; the two `mipmap-anydpi-v26/ic_launcher*.xml` files reference the
foreground, background and monochrome drawables. Bump `versionCode` in `app/build.gradle.kts` for every release you want phones to treat
as an update, then `./gradlew assembleRelease --no-daemon` (signed with `keystore/fantasy-release.jks` — keep it).

**Shipped 2026-11-14 as the APK v1.2** (`C:\Users\Sahil\Downloads\BCLFantasy-1.2.apk`). The Android project (outside this repo) also got a native splash that matches the web
loader (`ic_splash_logo` tile + "BCL FANTASY" wordmark) and `res/values-v31/themes.xml` with `windowSplashScreenBackground` = navy, because Android 12+ draws its own
startup splash first and it was white. Verified on an API 34 virtual phone: launcher icon (circle mask), startup splash, in-app splash. The themed-icon (monochrome)
layer was only previewed with `tools/preview_android_icon.js`, not seen on a device.
